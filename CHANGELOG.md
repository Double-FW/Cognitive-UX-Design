# Changelog

## Draft document pack 1.0 — 5 November 2026

This package was prepared against Cognitive-UX-Design commit `f3432fce3b1f4dba15c8453621f67b4e75c5c619`. It contains authored drafts, not an independently approved or already published release. Product tests and user evaluations have not been executed.

### Added

Six practical guides, the coverage/delivery map, the science evidence register and the reusable design/evidence template. New local COG pattern and MEM evaluation identifiers supplement existing QA identities. Added this changelog and package notes. Included the unchanged source gap review as historical rationale.

### Revised principles

All ten titles and their order are preserved. The introductory historical/neurotypical inference is replaced with a needs/evidence framing. Simplicity is described in terms of task burden rather than a fixed choice count. Memory support explicitly includes future intentions, current associations and recovery. Familiarity is distinguished from understanding.

Principles 5/8/9 now distinguish equivalent access from competing simultaneous output, meaningful salience from random novelty, and priority/persistence from channel choice. Principle 9’s earlier unconditional visual/audio/haptic mixture is expressly qualified. Principle 10 explains text-to-speech/AT and broad supported-mode choice without demanding separately recorded audio for every paragraph. These are substantive editorial changes, not a claim that the original source always meant the same thing.

### Existing guide extensions

- QA matrix: preserved CUX-01–36, G-01–06 and existing source test references; added section 7 with twelve MEM entry points. Updated G-05/source-scope commentary for the clarified notification principle and made the original pinned baseline explicit.
- Research/data plan: preserved the existing five-domain survey and governance text; added section 14 with six memory-study modules, module denominators, repeated-use/follow-up handling and evidence responsibilities.
- Vision/memory screen-reader guide: preserved VMR-01–08; added section 14 with six script scenarios and a recovery decision flow.
- README: replaced the brief repository description with role/task navigation, document ownership and evidence boundaries.

### Preserved

Existing licence bytes and historical gap-review content are unchanged. No original QA IDs are reused for new evaluations. Existing source content outside the changes listed above is retained in the three extended guides. New examples and tests have no fabricated participant observations or product passes.

### Review and publication

Structural/source-identity checks are recorded in VALIDATION_REPORT.md. Independent scientific/domain review, named owner appointment and repository publication remain pending. Publishing this pack does not assess product delivery. See the coverage register for current editorial/outcome status.
