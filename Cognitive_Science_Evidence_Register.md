# Cognitive science evidence register

**Double FW Ltd · Draft 1.0 · 5 November 2026**

This register owns the research-to-claim relationships for this pack. E1–E9 retain the review’s group identifiers; some groups contain several papers. A linked source is not proof that every related UX recommendation is validated. This is a bounded evidence register, not a systematic review, clinical assessment or claim that all findings replicate in every population.

## Evidence and claim rules

**N** identifies neuroscience/neuropsychological evidence; **B** behavioural experiments/reviews; **U** an applied UX inference. Prefer direct behavioural/user evidence for a product decision. Do not infer a mental state from one brain area or convert word counts, clicks, speech duration or pupil measurements into an invented capacity score.

Literature checks in the preceding review and source verification for this pack support the bibliographic baseline. Detailed demographic extraction, effect-size synthesis, independent peer review and population-specific transfer assessment remain pending unless separately recorded. Do not label this register “scientifically validated.”

## E2 — Delayed intentions, reminders and offloading

| Field | Record |
| --- | --- |
| Source / type | [Gilbert (2015)](https://pubmed.ncbi.nlm.nih.gov/25404057/); [Gilbert et al. (2020)](https://pubmed.ncbi.nlm.nih.gov/31448938/); [Gilbert (2011)](https://pubmed.ncbi.nlm.nih.gov/21414910/); B experiments; N human fMRI |
| Population and task boundary | Controlled delayed-intention/reminder tasks; the neural experiment examines storage/representation during an ongoing distracting task. Not a product trial with this repository’s intended users. |
| Supported claim | External cues can support future intentions; effort and confidence influence strategy. Neural representation of an intention does not establish its eventual completion. |
| Limitations | Not proof of an optimal notification frequency or a particular reminder design. No clinical inference from whether someone uses an aid. |
| Proposed application | COG-PM-01/02; COG-CF-01/02. These are U-level hypotheses pending product evaluation. |
| Review action | Verify demographic coverage, task comparability and effect estimates before a population-specific claim. |

## E3 — Event structure and memory

| Field | Record |
| --- | --- |
| Source / type | [Baldassano et al. (2017)](https://pubmed.ncbi.nlm.nih.gov/28772125/); N human fMRI with narrative perception/recall |
| Population and task boundary | Narrative experience and recall; distributed activity patterns and event structure, rather than ordinary web task transitions. |
| Supported claim | Experience can be organised into meaningful events related to later memory. |
| Limitations | A page transition is not automatically the same event boundary; no causal claim that every navigation causes forgetting. |
| Proposed application | COG-RC-01/02; continuity hypothesis. These are U-level hypotheses pending product evaluation. |
| Review action | Apply only as mechanism context; establish actual reorientation behaviour through user evidence. |

## E4 — Interference and item/association recognition

| Field | Record |
| --- | --- |
| Source / type | [Postle and Brush (2004)](https://pmc.ncbi.nlm.nih.gov/articles/PMC1200452/); [Hockley and Consoli (1999)](https://pubmed.ncbi.nlm.nih.gov/10479824/); N+B reanalysis; B experiment |
| Population and task boundary | Laboratory memory tasks and behavioural/fMRI reanalysis; item and association recognition are tested under controlled conditions. |
| Supported claim | Earlier information can compete with current processing; an item being familiar does not settle its current association. |
| Limitations | No predicted banking/shopping/AT error rate; no inference about individual impairment. |
| Proposed application | COG-CT-01/02; COG-CF-01/02. These are U-level hypotheses pending product evaluation. |
| Review action | Investigate comparable stale-context risks without treating the UI task as a clinical memory test. |

| Field | Record |
| --- | --- |

| Population and task boundary | Review of experimental and patient evidence concerning declarative/nondeclarative learning and memory systems. |
| Supported claim | Memory/learning is not one interchangeable faculty; facts and learned routines can have different characteristics. |

## E6 — Repeated warnings and habituation

| Field | Record |
| --- | --- |
| Source / type | [Kirwan et al. (2020)](https://pubmed.ncbi.nlm.nih.gov/33364992/); N+B warning-image experiment |
| Population and task boundary | Repeated software/security-warning images with behavioural and functional MRI observations. |
| Supported claim | Repeated exposure can show neural repetition suppression and habituation-related effects. |
| Limitations | Visual images do not directly establish spoken-alert outcomes; decreased signal does not prescribe random novelty. |
| Proposed application | COG-NT-01/02. These are U-level hypotheses pending product evaluation. |
| Review action | Replicate the relevant outcome question behaviourally in the intended channel and realistic exposure context. |

## E7 — Preparation and task resumption

| Field | Record |
| --- | --- |
| Source / type | [Trafton et al. (2003)](https://doi.org/10.1016/S1071-5819(03)00023-5); B interrupted-task experiment |
| Population and task boundary | Controlled interruptions with opportunities for goal preparation/rehearsal; task differs from cross-device customer journeys. |

## E9 — Stress and attentional control

| Field | Record |
| --- | --- |
| Source / type | [Liston et al. (2009)](https://pubmed.ncbi.nlm.nih.gov/19139412/); N+B psychosocial stress/functional MRI study |
| Population and task boundary | Studied psychosocial-stress context and prefrontal processing/attentional control, not a diagnostic assessment of individual customers. |
| Supported claim | Contextual stress can affect cognitive functioning in the studied setting. |
| Limitations | Not evidence that all memory is impaired or that time of day determines capacity; no justification for stressful testing. |

| Review action | Recruit/observe safely and distinguish self-reported context, observed performance and causal inference. |

## New-claim intake template

For a new claim, allocate a stable evidence-group ID after E9 rather than silently repurposing an old ID. Record full citation, correction/retraction status when checked, study design, population/channel, task, outcome and effect/uncertainty where available, competing evidence, supported claim, rejected overclaim, linked patterns and reviewer/date. Add the proposed UX hypothesis and what would count as contrary user evidence.

Never transfer a claim between visual, speech, braille or cognitive-needs populations without recording the transfer assumption. Keep the original paper’s observation distinct from an author interpretation and a product hypothesis. A new study may refine guidance without invalidating the principle itself.
